14  Template Example: Live Data Objects

Tip

This chapter is a working demonstration of the data pipeline, driven by the starter workbook at data/raw/workbook.xlsx. Once you understand the pattern, delete this chapter (and remove it from _quarto.yml) or adapt it.

14.1 How this works

The figure and table below are not hand-written. They come from data/raw/workbook.xlsx, which uses the same format as the Mid-Hudson CHA workbook:

  • A Master sheet - the roster of every indicator (Activate/Deactivate, Object_Type, Indicator Name, Object ID, Figure ID, data source).
  • A Dropdowns sheet - reference lists for the data-entry dropdowns (format codes, y-labels, sources, dates, …).
  • One sheet per indicator with a config block in columns A/B (Name, Table/Figure/Both, Object ID, Figure Type, X Column, …) and the data entered to the right of the Enter Data cell.

On every quarto render, the pre-render hook in _quarto.yml runs scripts/generate_chapter_objects.py, which reads the indicator sheets and writes one include file per object into chapters/_generated/objects/. This chapter pulls them in.

The Poverty Rate sheet is a figure (Figure 14.1); the Total Households sheet is a table (Table 14.1).

14.2 To add your own indicator

  1. Copy an indicator sheet (Poverty Rate or Total Households).
  2. Set the config cells in column A/B - especially Name, Table/Figure/Both (figure or table), Object ID, and (for figures) Figure Type / X Column.
  3. Fill the data to the right of the Enter Data cell: the row-label column (col F) plus value columns, with per-column format codes in the row just above.
  4. Add the indicator to the Master roster (optional, for tracking).
  5. Reference it in any chapter with {{< include _generated/objects/<object_id>.qmd >}} (e.g. fig-<id> or tbl-<id>), run the generator once, then quarto render.

See scripts/WORKBOOK_SCHEMA.md and scripts/PIPELINE_USAGE.md for full details.
